# Zenvy E-commerce React Tailwind

Responsive e-commerce frontend made with React, Vite, Tailwind CSS and React Router.

## Run Project

```bash
npm install
npm run dev
```

## Pages
- Home
- Products
- Product Detail
- Cart
- Login
- Register
- Deals
- About
- Contact
- Admin Dashboard

## Tech
- React
- Tailwind CSS
- React Router DOM
- Lucide Icons
